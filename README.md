# Sheikh Al-Islam Ibn Taymiyyah Quran Memorization School

A responsive single-page website for Sheikh Al-Islam Ibn Taymiyyah Quran Memorization School in Al-Haer, Riyadh, Saudi Arabia.

## 🌐 Live Website

https://ibntaimiaquranschool.netlify.app/

## 📌 About the Project

This website was developed as a modern digital presence for the Quran memorization school. It provides visitors with essential information about the school, its programs, schedule, registration, location, and contact channels.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern Islamic-inspired visual identity
- School information and history
- Quran memorization and revision programs
- Registration and communication links
- Google Maps location
- WhatsApp integration
- Maknon affiliation and donation links
- Mobile navigation menu

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Netlify
